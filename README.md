### 🔧 Featured project

**[nqf-lint](https://github.com/cleitonaugusto/nqf-lint)** — a pre-flight linter for
quantum-chemistry setups. It catches silent input errors (impossible electron-count/spin,
Bohr/Ångström unit mistakes, bare atoms, non-reproducible geometry) *before* a calculation
runs for hours on a broken input.

- **Rust core + Python bindings (PyO3)**, published on both registries:
- `pip install nqf-lint`  ·  `cargo install nqf-lint`
